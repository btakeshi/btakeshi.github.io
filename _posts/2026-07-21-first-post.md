夏休みに入り、勤務時間が半日になったので、久しぶりにサイト構築しています。

最近課金した Antigravity CLI に作ってもらいました。以前、色々と調べながら作ってみた Jekyll ベースの最小構成のブログサイト、
Github にアップするだけでサイトになるように GithubPages を使って、とプロンプトを出しただけで作ってくれました。
なんと Github へのアップコマンドまで実行してくれました。

調子に乗って機能も追加してもらいました。23時ころから始めて、2時間ぐらいでの成果です。

### 数式は KaTeX

どうしても数式は必要なので、お気に入りの KaTeX を使えるようにしてって頼んだら、以下のとおりになりました。
インライン数式 $y=x^2$ と、別行建て数式が問題なく使えるようになりました。

\\[
\dfrac12x^3
\\]

### sitemap 機能を追加
